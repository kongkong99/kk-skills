# 声音与资源

声音用来支持可见动作和表达节奏。先保证人声清晰，再加入需要的音效或背景音乐；不默认每个镜头都配声音。

| 动作 | 可选声音 | 检查 |
| --- | --- | --- |
| 点击或确认 | 短点击 | 与可见操作对齐，不掩盖词首 |
| 镜头或界面移动 | 短 whoosh | 声音有完整主体，尾音自然 |
| 结果出现 | 轻提示音或无音效 | 不把声音当作真实软件执行证据 |
| 打字 | 有对应输入的键盘声 | 随可见输入停止，不持续铺在停顿下 |

将声音的可听起点或重音与画面动作对齐，而非机械对齐文件头。短镜头也应保留适当声体与尾音；根据原音效选择片段，不能把完整声音任意截断后只剩低频或咔嗒。淡入淡出保护衔接，混音避免削波，检查手机小音量下的语音清晰度。

## 包内原创合成音效

[catalog.json](../assets/catalog.json) 只登记以下由包内脚本生成的声音：

- `mouse-click.wav`：0.12 秒单声道短点击。
- `zoom-whoosh.wav`：0.38 秒单声道移动提示。

从技能目录执行即可重建，脚本只使用 Python 3 标准库：

```bash
python3 scripts/make_sfx.py
```

随机种子固定，重复执行生成相同内容；脚本会覆盖这两个包内 WAV。实际项目应导入副本。它们是简单声音起点，不代表真实录制的鼠标或软件声音。

本包不包含外部音效库录音。需要键盘、音乐或其他声音时，使用用户提供或当前环境已授权的资源，并保留必要的来源信息；缺少资源时可以交付不加该声音的版本。不要把库文件的本地存在当成公开再分发授权。

音效检查须听实际混音和导出：爆音、尾音截断、人声遮盖、不同设备音量差异，以及音画是否贴合。只能测量峰值而不能试听时，说明验证范围。

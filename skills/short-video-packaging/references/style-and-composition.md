# 风格与构图

以下是制作时可调整的选项，用户当前说明优先。通常从素材和用途推断并开始工作，只对会改变交付的关键冲突提问。

| 项目 | 未指定时 | 可以怎样调整 |
| --- | --- | --- |
| 比例与分辨率 | 沿用主要素材；明确竖屏需求用 9:16 | 横屏教程、方形信息卡、平台指定尺寸 |
| 语速与节奏 | 自然语速，去掉明显冗余 | 精简快节奏、完整课堂式讲解 |
| 字幕 | 高对比、短句、少量重点 | 品牌色、逐词强调、双语字幕 |
| 人物与界面 | 按当前信息重点切换 | 全屏人物、全屏录屏、分屏或小窗 |
| 标题 | 需要引导主题或章节时出现 | 用户指定时持续显示 |
| 小窗 | 需要人物连续性且有空位时添加 | 圆形、矩形及适合内容的位置 |
| 背景与文字底板 | 优先保证对比与阅读 | 纯色、轻渐变、简洁纹理或细微动画 |
| 新增图片与音乐 | 使用现有素材；不预设生成配额 | 有明确解释作用且任务需要时再制作 |

## 字幕层次

分清主题标题、口播字幕和解释图形：主题给方向，字幕表达说话内容，图形说明关系或证据。不要同时用三块大字重复同一句。

静态重点通常足够。需要关键词动画时，可用 [keyword-pulse.mjs](../assets/keyword-pulse.mjs) 的 `keywordScale` 生成一次短促放大：传入字幕卡相对秒数 `time`、词组开始 `start`、字幕结束 `captionEnd`。函数只返回比例，不选择词、不控制颜色，也不直接生成字幕。默认峰值 1.2、时长 0.28 秒只是可调起点；函数将峰值限在 1–1.25 以减少碰撞。

缩放围绕真实词时触发，给峰值预留空间，避免逐字反复抖动。用户指定其他字幕效果时按其要求实现，勿将这个示例当作唯一风格。按时间求状态，拖动回同一帧应得到相同结果。

## 构图检查

先做稳定、可读的落定帧，再安排入场和离场。人物眼口、操作目标、图表标注和字幕均需有空间。小窗挡住内容时可以调整位置、大小或布局，不固定某一角落。

用户选择圆形小窗时，按输出像素验证真圆，不依据宿主“椭圆”参数猜测；不要拉伸人脸。使用底部渐变时，它是提高局部对比的空间蒙层，避免压暗关键界面内容。移动背景应保持低对比和连续，不能抢占阅读注意力。

在最终输出尺寸与实际手机观看尺寸检查最长字幕、最大关键词、最紧裁切和画面切换；不要仅凭编辑器中缩小的预览判断可读性。

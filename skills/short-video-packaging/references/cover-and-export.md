# 封面与导出

## 封面选择

用户需要封面时，从实际素材或专门设计中选择能表达主题的画面。人物清晰、表情自然、标题易读，避免眨眼、拖影、转场中间帧和字幕遮脸。比较合理候选，保存与交付要求匹配的图片。

封面文件与视频第一帧是两件事。默认单独交付封面，不把封面插入时间线，也不承诺平台自动采用该图片作为缩略图。

## 仅当用户要求封面成为首帧

1. 将选定 PNG 放在时间线最上层，从第 0 帧开始，采用一帧或编辑器支持的最短时长，覆盖画面而不移动已有音轨与剪切点。
2. 检查素材、层级、启用状态、几何和透明度；不要把平台封面设置误认为时间线已发生变化。
3. 导出后比较实际解码首帧与选定封面，并观看封面到动态开场的衔接，避免闪跳。

从技能目录可运行：

```bash
python3 scripts/check_cover_first_frame.py \
  --video '/absolute/path/final.mp4' \
  --cover '/absolute/path/selected-cover.png' \
  --output-dir '/absolute/path/cover-check'
```

需要 Python 3 与 FFmpeg；默认使用 PATH 中的 `ffmpeg` 命令，可用 `FFMPEG_PATH` 环境变量或 `--ffmpeg '/absolute/path/ffmpeg'` 指定，命令行参数优先。脚本排除附件缩略图流，读取实际首帧，检查尺寸并计算 SSIM，输出 `first-frame.png` 和 `report.json`。

退出码 0 表示尺寸相同且达到相似度门槛，1 表示不匹配，2 表示输入或工具错误。默认门槛 0.98 是复核起点，不代替人工检查，也不能证明封面质量或时间线图层确实存在。失败后先排查错帧、裁切、遮挡与颜色处理；不要从错误输出抽帧替换原选封面以制造通过。

## 最终交付

核对编码文件能解码、时长和尺寸符合要求，并观看实际导出画面的开头、关键切点、最拥挤构图及结尾。检查真实文本、字体、字幕换行和素材比例。听实际导出的人声、剪切与声音衔接。

交付任务要求的成片、实际可提供的编辑源及封面。编辑工具不能提供完整可移植工程时，交付可用源素材与编排说明并说明范围，不将渲染视频称为分层可编辑工程。没有执行过的试听、播放或平台封面设置不要报告为已通过。

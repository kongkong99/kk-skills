# 短视频包装

将素材组织成听得清、看得懂的短视频。先确定讲解内容和时序，再用画面帮助观众理解；镜头、字幕与音效服从本次内容和用户风格。

## 开始使用

可直接提出：

- “把这段口播剪成 60 秒竖屏知识视频，去掉明显停顿，字幕简洁，不要额外生成图片。”
- “把这段录屏和讲解做成软件教程，放大关键按钮，保留可编辑工程。”
- “先按这份逐字稿出分镜，暂时不剪视频。”

先检查已有素材和项目，识别交付目标、内容、输出比例、目标时长和可用工具。只询问会阻塞制作的缺项；用户已给定的信息不重复询问。没有素材时可以先出分镜，但不要虚构音频词时或声称已经剪出成片。

默认保留原语言和自然语速，以现有素材为主，使用清晰字幕和必要的画面强调。未指定画幅时沿用主要素材比例；对于明确的竖屏平台任务可采用 9:16 并说明。其他可选项按 [风格与构图](references/style-and-composition.md) 决定；无需先让用户填写一整张配置表。

## 工作流

1. **整理内容与素材。** 读取录音、视频、可靠转写和截图；区分真实录屏、示意重建与生成素材。检查转写中的专有名词、数字和不确定词。记录源时间与成片时间，避免剪掉停顿后仍使用原词时。
2. **完成口播主剪。** 在不改变原意的前提下，处理重复、失误和明显拖沓的停顿；用户只要包装时，不擅自重写其观点。气口处理和变速方法见 [口播剪辑与同步](references/speech-and-timing.md)。先锁定会改变总时长的主剪，再添加字幕、动画和音效。
3. **按语义规划画面。** 将讲解拆成有意义的段落，记录“口播落点 → 需要理解什么 → 素材依据 → 画面动作”。可用真实录屏说明操作，用图解说明关系，用结果画面兑现前文。短任务可用简洁表格，无需机械逐句加效果。分镜和结果揭晓见 [画面与分镜](references/visual-storyboard.md)。
4. **建立可编辑包装。** 按宿主能力分开保留人物、录屏、图形、标题、字幕和声音。字幕对应最终口播，重点词可以静态强调或单次动画；使用真实词时，不按字数均分后声称精准同步。新增图形应补充关系、证据或判断，避免和字幕重复堆字。
5. **安排声音。** 按可见动作选择点击、移动或结果提示；留出完整声体和自然尾音，口播保持清晰。可使用包内原创合成音效，方法见 [声音与资源](references/audio-and-assets.md)。不因安装本技能就默认调用生成服务或导入外部素材库。
6. **输出并检查。** 用户要成片时，在可用能力范围内完成工程和导出；若缺少剪辑、渲染或音频检查能力，交付已完成的部分并准确说明缺口。需要封面时按 [封面与导出](references/cover-and-export.md) 处理，不默认改写视频第一帧。

## 制作判断

- **节奏随内容变化。** 在观点转折、操作发生或结果出现时改变画面。允许必要阅读停留，不规定每几秒必须切换，也不规定开头的图片数量。
- **素材服务于内容。** 生图、背景音乐、人物小窗、固定标题和装饰背景都是按需要启用的选项。未要求时不为了凑效果数量生成图片。
- **构图保证阅读。** 人物小窗的位置与形状由界面空位、字幕和用户风格决定。检查最紧裁切及最大字号时仍不遮脸、不遮操作目标。
- **参考须实际观察。** 用户指定某个参考视频时，读取可用的参考画面与声音，区分观察结果和实现推测。无法访问参考时说明限制，不套用一个创作者的历史配置。
- **真实与示意分清。** 模拟 UI 不作为真实执行或真实结果的证据，可能混淆时清楚标识。用户明确不要画面标志时，在交付中说明示意性质。制作 WorkBuddy 演示素材时可选用 `workbuddy-demo-animation`；未安装时仍可使用真实录屏或通用图解完成本技能。

## 依赖与验收

本技能是制作工作流，不是完整视频编辑器。分镜可仅用文本能力；实际成片需要可读取素材的剪辑、字幕、合成及导出工具，语音转写按环境可用能力完成。没有指定必须使用的编辑器或付费服务。

包内工具：`scripts/make_sfx.py` 只需 Python 3 标准库；可选的 `scripts/check_cover_first_frame.py` 需 Python 3 和 FFmpeg；字幕缩放辅助函数是标准 JavaScript ES module，需要接入所用字幕渲染器，不是完整字幕模板。

检查实际导出结果：语义完整、音画同步、字幕无错字和裁切、界面目标可见、过渡自然、音效不盖住人声、尺寸和时长符合要求。听过才报告声音检查通过，看过实际导出才报告画面通过。交付成片和实际可提供的编辑源；分镜任务只交付分镜，不声称完成渲染。

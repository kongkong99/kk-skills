# 口播选 B-roll

根据台词决定要不要切空镜、选哪一类画面、怎么筛片。先锁口播轨，再配画面；不为「好看」满铺。

## 何时用

- 用户要给口播 / talking-head 配 B-roll、空镜、cutaway
- 用户问「这句话该放什么画面」「库存怎么搜」「哪些别放」
- 用户交出逐字稿或时间线，要按句标注画面类型

不要用本 skill 去拍片或剪片软件操作；只产出选片决策与镜头清单。

## 核心规则

对每一句台词问：**观众现在必须看见什么？**

- 答不上来 → **留人脸**
- 答得上 → 按下方优先级选片，再决定全屏还是叠在讲述者身上

空镜服务理解、盖跳剪、换话题或情绪转折；结论、CTA、求信任的话优先回人脸。

## 选片优先级（能用上面的就不用下面的）

1. **创作者自拍**：手部、桌面、现场操作、走路/坐下等第二机位
2. **真证据**：真实产品界面录屏、所引文章/数据截图、真实评论或聊天（需打码）
3. **过程演示**：台词含「怎么做 / 步骤」时的逐步操作
4. **对得上的库存**：台词点名的环境或动作（说「机场」才用机场，不用「商务感」万能片）
5. **气氛空镜**：只换气或托情绪，少用；多了像凑时长

## 台词 → 画面类型

| 台词在做什么 | 放什么 | 不放什么 |
| --- | --- | --- |
| 开场自我介绍 / 点题 | 留人脸 2–3 秒 | 一上来就切空镜 |
| 点名具体物 / 地 / 动作 | 直给该物、地、动作 | 「感觉像」的万能商务空镜 |
| 「怎么做 / 几步」 | 录屏或实操过程 | 随机打字手 |
| 数字、对比、框架、漏斗 | 图卡或简单 MG | 无关股市 K 线、握手特写 |
| 引用某产品 / 某文 | 真界面或真标题截图 | AI 生成的假界面当证据 |
| 抽象概念 | 简单隐喻图，或留人脸讲清 | 无关联的日落、星空、粒子 |
| 要盖的跳剪 / 口误 | 相关细节特写盖剪口 | 完全无关的炫酷镜头 |
| 结论 / CTA / 求信任 | 回人脸 | 关键句盖满空镜 |
| 换话题 / 换场景 | 建立镜头（远景或环境 2–4 秒） | 硬切下一段人脸 |

## 候选片五关（不过就换）

1. **故事位**：拿掉后这句是否更难懂？更难懂才留
2. **够具体**：静音看，约 3 秒内能认出拍的是什么
3. **好切**：动作有进有出，不是半路截断
4. **画幅能活**：目标竖/横屏裁完主体仍清楚，别贴边
5. **有权用**：许可证或可商用范围清楚

## 时长与排版

- 单段空镜通常 **2–5 秒**；复杂界面可读到 **4–7 秒**
- 信息必须读完的图卡 → **全屏**；只需示意 → **小窗叠在讲述者上**
- 约 1–2 分钟口播：至少混用 **3 类**（如直给 + 录屏 + 图卡），避免全片同一种打字手
- 比例起点（非铁律）：快节奏短视频约一半空镜；标准口播约 4 成空镜；人脸很重要的教程约 3 成空镜
- 口播人声常开；空镜原声静音或压低

## 交付格式

有逐字稿时，按句输出表（缺时间戳则标「待对齐」）：

| 原句 / 片段 | 决策 | 画面具体描述 | 获取方式 | 备选 |
| --- | --- | --- | --- | --- |
| … | 留脸 / 直给 / 录屏 / 图卡 / 库存 / 气氛 | 主体、动作、构图、建议秒数 | 自拍指令 / 录屏步骤 / 中英搜索词 / MG 说明 | 取不到时怎么办 |

末尾汇总：

- 必拍清单
- 必录屏清单
- 库存搜索词（中英）
- 明确不建议用的片型
- 待确认授权或素材缺口

没有稿子时：先要一小段真实文案或时间线；用户只要方法时，用明确标注的虚构短例演示上表。

## 常见翻车

- 全程满铺空镜，抹掉人脸信任
- 直译式：每说「电脑」就切笔记本
- 切在句子中间打断语流
- 素材声盖过口播
- 无字幕时切离嘴型，静音观众丢线索
- 用库存/生成图冒充「真实结果」证据

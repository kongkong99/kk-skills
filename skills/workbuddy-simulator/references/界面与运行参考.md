# WorkBuddy 界面与运行参考

以下为 WorkBuddy 5.9.3 的单次观察整理，仅供复刻视觉结构；界面和功能会随版本变化。为保护个人信息，公开版不包含原始截图或视频。

## 可观察到的界面结构

原始采集截图顶部的紫色电脑控制标识是采集时的临时状态，不是普通 WorkBuddy 窗口控件。正常状态下：左上为红、黄、绿三个 macOS 圆形按钮，模拟时按此绘制。

截图为 3024×1772。全宽界面左侧栏约占 18.5%，淡冰蓝色；顶部包含 WorkBuddy、版本、发现应用和新建任务、助理、专家·技能·连接器、定时任务、资料库、更多等入口，下面是置顶与任务列表。当前任务以浅蓝背景高亮并显示旋转状态。

任务主区使用接近白色的淡灰蓝背景。顶栏显示任务标题、搜索和分享图标；用户消息是靠右的浅青色圆角气泡。回复区有 WorkBuddy 图标与名称、灰色「已处理」计时、当前阶段及逐步出现的内容。底部是白色大圆角输入框，含加号、权限、连接器、模型、麦克风；运行时右侧是深青色圆形停止按钮。

右侧面板打开时，全宽比例大致为左栏 18.5%、对话区 41%、右侧面板 40%。面板有标签栏、打开浏览器、查看工作空间、打开终端，以及产物列表。具体界面随版本、账号和窗口尺寸变化。

## 实际观察的过程与边界

所采任务最初显示准备连接器，接着出现深度思考、处理技能、流式文本、调用 MCP 工具，并打开右侧产物区，最后被用户停止。演示任务误处于设计模式，创建过一个演示设计产物。画面中显示的完成状态、任务计划细节、工具步骤和精确动画节奏如果没有其他素材验证，均应视为为了教程而设计的模拟，不应声称是真实记录。不同任务不必强行出现相同工具或相同顺序。

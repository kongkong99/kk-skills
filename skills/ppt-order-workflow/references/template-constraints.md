# 模板约束表：口径、抽取方法、默认版式

阶段 1 解析参考模板、或用户的内容需要一种目录里没有的版式时，读这份文件。

## 目录

1. 约束表字段口径
2. 从参考 PPTX 抽约束
3. 默认 9 种版式骨架
4. 新增或修改版式

---

## 1. 约束表字段口径

约束表就是工单里的「模板目录」sheet，一种版式一行。

| 字段 | 口径 | 例 |
|---|---|---|
| 模板（下拉值） | `中文名（ID）`，脚本自动拼 | 三卡片（three-card） |
| 模板ID | 英文、数字、`-`、`_`；按版式的**用途**起名，不按页码起名，模板页序变了 ID 也不变 | three-card、case-photo |
| 中文名 | 给人看的名字，说出版式长相或用途 | 三卡片、案例大图 |
| 页型 | 这页在叙事里的角色；多种版式可以同属一个页型 | 观点页 |
| 长什么样 | 一句大白话描述布局，让没见过模板的人也能想象出来 | 顶部标题，下方三张等宽卡片 |
| 适合什么时候用 | 使用场景和禁忌 | 恰好 3 个并列点；多于 3 个必须拆页 |
| 必填字段 / 可选字段 | 用 `、` 分隔，取自：主标题、副标题、正文块1–3、配图描述、配图URL文件。没列到的字段即「不适用」 | 主标题、正文块1、正文块2、正文块3 |
| 正文槽位数 | 用到几个正文块，脚本从字段自动算；正文块必须从 1 起连续 | 3 |
| 并列点数上限 | 全页正文行数之和的上限（一行一个点） | 3 |
| 主标题 / 副标题 / 正文块字数上限 | 去掉空白后的字符数；正文块是**每块**上限；字段不适用填 `/` | 20 / 28 / 36 |
| 内容形态 | 这页对应的论证动作和容量，取 `script-constraints.md` §1 的词表；讲稿按它组织内容 | 并列 / 分类（3 项） |
| 配图需求 | 必需 / 可选 / 无，脚本按配图URL文件的必填性自动算 | 无 |
| 节奏定位 | 开场、转场、主体、节奏点、收尾。「节奏点」版式有使用次数提醒 | 节奏点 |
| 来源 | 参考模板第几页、什么版式名；默认骨架写「内置骨架」 | 模板第 6 页（Title Only） |
| 本套使用次数 / 占比 | 公式自动统计 | 1 / 9% |

## 2. 从参考 PPTX 抽约束

用已有的幻灯片读取能力（如 pptx 技能或 python-pptx）读模板，本 Skill 不重写解析器。在线幻灯片：有能读取它的连接就直接读，没有就请用户导出成 PPTX。

**1. 先去重，再登记。** 模板里常有多页长得一样、只是示例文字不同。按「形状的种类、数量、位置」判断是否同一版式：结构相同的算一种，记下第一次出现的页码作为来源。目录页、纯装饰页、示例数据页（图表模板）也要登记，但标注适用场景。

**2. 逐个版式确定字段映射。** 看每个文本框和图片框在版面上的角色，映射到工单字段：

- 最大、最靠上的标题框 → 主标题；紧跟其下的小字 → 副标题
- 并列的同尺寸文本框（卡片、栏）按从左到右、从上到下 → 正文块1、2、3
- 图片占位或明显的图片区 → 配图描述 + 配图URL文件
- 页脚、页码、Logo 等每页固定的元素不进字段，由全局设置统一提供

超过 3 个并列文本框的版式（如四宫格），工单只有 3 个正文块，无法承载，在「适合什么时候用」里写明不支持，或者请用户确认后改用 3 栏版式。

**3. 估字数上限。** 对每个映射到字段的文本框：

```
字号 S（pt）：取第一段文字的字号；读不到则取母版对应占位符的字号；仍读不到，标题按 32、正文按 18
每行字数 = floor(框宽pt ÷ S)            # 中文字宽约等于字号；1pt = 12700 EMU
可放行数 = floor(框高pt ÷ (S × 1.3))
容量 = 每行字数 × 可放行数
上限 = floor(容量 × 0.8)                 # 留 20% 呼吸感
```

- 标题类字段只算 1 行，最多 2 行：`上限 = 每行字数`（两行版式则 ×2 再 ×0.8）。
- 框里有设计师留下的示例文字，而且示例排得很舒服时，用 `min(上面的估算, 示例字数 × 1.2)`，示例比估算更能代表设计意图。
- 并列点数上限 = 正文块数 × 每块可放行数；卡片类每块固定 1 点。
- 估算只是起点。拿不准就保守取小，出片回读时如果发现溢出，回到约束表调小上限，再重跑 build。

**4. 写进 JSON 的 `templates`。** 字段名与 `order-schema.md` §5 一致。用户的模板替换默认骨架，不与默认 9 种混用；但如果用户模板缺了某个必要页型（常见：没有结束页），可以从默认骨架里补一种，`source` 写「内置骨架」，并在交付工单时告诉用户。

**5. 跑 `build` 前确认约束表能通过版式自洽校验。** 脚本会检查字段名、正文块连续性、字数上限是否齐全。

## 3. 默认 9 种版式骨架

没有参考模板时使用。出片时用已有的幻灯片生成能力按「长什么样」画出统一风格，配色、字体取全局设置。

| 中文名（ID） | 长什么样 | 适合什么时候用 | 必填 | 可选 | 点数上限 | 字数上限 主/副/正文块 | 节奏 |
|---|---|---|---|---|---|---|---|
| 封面（cover） | 满版品牌色或背景图，居中大标题，下方一行副标题，底部一行署名（讲师｜活动｜日期） | 第 1 页，只用一次 | 主标题、正文块1 | 副标题、配图描述、配图URL文件 | 1 | 18 / 28 / 30 | 开场 |
| 讲师介绍（speaker） | 左侧讲师照片，右侧姓名、头衔和 3 行以内履历要点 | 开场第 2 页；对外分享需要建立信任时 | 主标题、副标题、正文块1、配图描述、配图URL文件 | — | 3 | 10 / 24 / 72 | 开场 |
| 章节过渡（section） | 大号章节名居中，可带一句本章要点，大面积留白或品牌色底 | 进入新章节前；3 章以上才需要 | 主标题 | 副标题 | 0 | 12 / 24 / — | 转场 |
| 双栏文字（two-col） | 顶部标题，下方左右两栏，每栏最多 3 行（首行可作小标题） | 对比（之前/之后、A/B）或两件并列的事 | 主标题、正文块1、正文块2 | 副标题 | 6 | 20 / 28 / 60 | 主体 |
| 三卡片（three-card） | 顶部标题，下方三张等宽卡片，每张一行「卡片标题：一句说明」 | 恰好 3 个并列点；多于 3 个必须拆页或换版式 | 主标题、正文块1–3 | 副标题 | 3 | 20 / 28 / 36 | 节奏点 |
| 观点页（viewpoint） | 上方一句大字观点，下方 3 行以内论据，右侧可放小配图 | 抛出判断并给理由；主体的主力版式 | 主标题、正文块1 | 副标题、配图描述、配图URL文件 | 3 | 24 / 30 / 80 | 主体 |
| 金句页（quote） | 整页只有一句大字金句，可带一行出处或补充 | 章节收束或全场落点；全套少量使用 | 主标题 | 副标题 | 0 | 30 / 20 / — | 节奏点 |
| 图文页（img-text） | 左侧大图（截图/照片/示意图），右侧标题 + 4 行以内说明 | 演示、案例、截图讲解 | 主标题、正文块1、配图描述、配图URL文件 | 副标题 | 4 | 20 / 28 / 90 | 主体 |
| 结束页（ending） | 一句行动号召 + 二维码或联系方式，只留一个出口 | 最后一页，只用一次 | 主标题 | 副标题、正文块1、配图描述、配图URL文件 | 2 | 16 / 24 / 40 | 收尾 |

这张表与脚本里的 `DEFAULT_TEMPLATES` 一一对应。改了其中一边，另一边同步改，再跑 `selftest`。

**画默认骨架时的统一规则**

- 16:9；四周留白不小于 0.5 英寸；同一字段在各页的位置、字号保持一致。
- 主色用于标题和强调元素，辅色用于卡片底和分隔线；没有品牌色时用中性深灰配一个强调色。
- 配图区先画浅灰占位框并写上配图描述，拿到真实素材后替换；用户同意保留【待补】时，占位框里写「待补：缺什么」，不放替代图。

## 4. 新增或修改版式

内容需要的版式目录里没有时（例如要放 4 个并列点，或要一张时间轴），按顺序做：

1. 先看能否拆页或换现有版式解决，能解决就不加新版式。
2. 必须新增时，在约束表加一行：起 ID 和中文名、写「长什么样 / 适合什么时候用」、定必填和可选字段、定并列点数和字数上限。参考模板里有对应页就按 §2 估算；没有就按默认骨架的尺度给保守值，`source` 写「新增」。
3. 跑 `build`，版式自洽校验通过后才允许页面引用它。
4. 交付工单时告诉用户新增了哪种版式、为什么。

修改上限（比如出片发现溢出）：改约束表 → 重跑 `build` → 被新上限卡住的页面按超容量规则拆页或换版式，不要为了让旧文案通过而调大上限。

一套工单的版式数量不追求多。同一页型反复使用是一致性；单调感由页型节奏决定（开场→主体→节奏点→主体→收尾），不由版式种类数决定。

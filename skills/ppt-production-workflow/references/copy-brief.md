# 文案简报与切入角度

分析模板与资料时使用。区分用户明确要求、材料可核验事实和设计假设；模板示例不能自动变成本次活动的身份或结论。

## 读什么

| 线索 | 可帮助判断 | 不应推断 |
| --- | --- | --- |
| 用户明确的主题、受众、目标 | 重点、术语深度、最终需要回答的问题 | 未提供的业绩、经历或受众背景 |
| 活动名称和说明 | 正式程度、演讲与演示的比例 | 仅凭“实战”就承诺未经验证的效果 |
| 品牌规范与视觉模板 | 字体、色彩、空间、可使用的图形 | 从 Logo 自动推断“不能提竞品”等政策 |
| 示例标题和内容 | 文字长度、视觉层级 | 继承样例中的人名、城市、日期、数字 |
| 现有大纲和参考材料 | 已确定观点、证据、术语 | 为配合版式改写事实 |

没有模板时，从需求与资料建立文案简报；没有足够依据的判断标为假设，影响结果且不能合理选择时再询问。

## 简报

用简洁表格记录受众、目标、语气、已知事实、需要的证据、品牌要求、语言与来源。标题可以短，专有名词和数字要准确。是否使用比喻、幽默、故事或行动号召按受众与目标决定，不要求每场演讲都用同一种结构。

## 选择切入角度

主题宽泛时，可提出 2–3 个有实质区别的角度，说明主张、核心证据、开场和结尾。已有主线时直接沿用。用户要求选方向时等待；用户授权自主完成时选择最匹配的一条并说明原因，继续规划。

结尾可以是回顾、讨论、决策请求或下一步；只有用户需要时才添加扫码、联系方式或领取资料。

## 冲突处理

用户的明确要求优先于模板的视觉暗示。证据与事实优先于漂亮比喻。资料之间冲突时标出来源和差异，不自行把推断当作确定结论。版式承载不了重要证据时改布局或拆页，不撤掉证据。

# 封面必须落到视频首帧

适用于本用户的成片包装。输入：锁定的口播时间线、实际视频、主题标题与底部渐黑。输出：选定封面 PNG、时间线第 0 帧的封面图层、成片首帧校验报告。

## 选帧与合成

- 至少比较 3 个实际候选帧，记录时间线帧号/秒数、眼神与表情、清晰度、遮挡、接回开场的连续性。优先在开场附近找合适画面；必要时扩大范围。
- 人物睁眼、脸完整、表情自然，标题在手机尺寸下可读。排除眨眼、拖影、尴尬口型、转场中途和字幕遮脸。没有人物的片子选择能代表主题的主体画面。
- 第 0 帧可以胜出，但必须有候选比较和选择理由，不能仅把当前第一帧另存后就跳过选帧。
- 导出与成片同尺寸的无损 PNG，包含全程主题标题和底部透明到黑渐变。不要把已有标题和渐变叠加两次。不要把中途的口播字幕、半透明入场文字无意烙进封面。

## 时间线中的具体动作

1. 把选好的 PNG 作为图片素材导入工程。
2. 放到画面最高层，起点 0、时长 1 帧；编辑器限制时使用其最短时长并记录。启用、全画布、100% 不透明，无入场渐变、无位移动画、无转场。检查特殊字幕层不会叠出第二份文字。
3. 覆盖第 0 帧的画面，保留原片和所有音轨时间。不得插入黑场、静音片头，或把人物钩子向后推。
4. 回读实际图层的素材 ID、起点、时长、层级、几何和启用状态。记录到本次项目的制作记录，不写进通用 Skill。
5. 检查第 0、1 帧及开场动态。后面的画面继续既定运镜；如果封面与第 1 帧构图差异造成明显闪跳，换一个更接近开场的合格候选或调整封面构图，不能靠长时间定格掩盖。

## 对导出文件验收

先选定封面并完成图层，再导出视频，最后运行：

```bash
python3 scripts/check_cover_first_frame.py \
  --video '/absolute/path/final.mp4' \
  --cover '/absolute/path/selected-cover.png' \
  --output-dir '/absolute/path/cover-check' \
  --ffmpeg '/absolute/path/ffmpeg'
```

`--ffmpeg` 在可从 PATH 找到 FFmpeg 时可省略。脚本只依赖 Python 标准库和 FFmpeg，不依赖 Pillow/NumPy。它排除文件中内嵌的封面/缩略图流，解码实际视频的第一帧、检查同尺寸并计算 SSIM，输出 `first-frame.png` 和 `report.json`。默认相似度门槛 0.98 是复核门槛，并非跨编码器的视觉质量定律；失败不得通过降低门槛来掩盖选错图层、裁切或颜色错误。

- 退出 0：图像比较通过；退出 1：尺寸/相似度不通过；退出 2：输入或工具出错。检查错误不等于通过。
- 通过只证明所选 PNG 与输出首帧接近，不能证明它是最佳封面，也不能证明封面图层存在。仍需上述候选记录和时间线回读。
- 未达门槛时先查错帧、遮挡、缩放、裁切和颜色处理。若确认内容/几何一致且仅有可接受的编码或暗部差异，可记录“机器未达门槛、人工视觉复核通过”及证据；保留原始失败报告，不改分数或宣称自动检查通过。不能用总分替代检查脸、文字和开场衔接。
- 禁止在失败后从错误成片抽首帧替换“所选封面”，制造自证通过。
- 图片比较也不证明音频完整；核对总时长、原声和开头音效起点不变，再检查最初几秒的自然衔接。无法试听时如实说明。
- 交付时附成片、单独封面和简短验收结果。平台是否采用这张图作为列表缩略图需另行确认。
